## 💡 คำแนะนำเพื่อความปลอดภัย

> 🔑 • ผสม **ตัวอักษร + ตัวเลข + สัญลักษณ์** เพื่อความปลอดภัยสูงสุด<br>
> 🔑 • อย่าใช้รหัสผ่านเดิมซ้ำหลายบัญชี<br>
> 🔑 • อย่าแชร์รหัสผ่านให้ผู้อื่นทราบ
